# Қазақша қаріп және бейімделген интерфейс: тексеру есебі

## Орта мен ауқым

- Тармақ: `feat/kazakh-typography-responsive-ui`.
- Браузер: Windows 11 жүйесіндегі Google Chrome 153.0.8010.53, headless режимі, WebGL үшін SwiftShader. Бұл браузер эмуляциясы; физикалық телефон немесе планшет пайдаланылған жоқ.
- CSS көрініс өлшемдері: 320×700, 360×780, 390×844, 430×932, 768×1024, 820×1180, 1024×768, 1440×900, 844×390, 932×430 және 1180×820. Соңғы үшеуі көлденең бағытты қамтиды.
- `tools/responsive-qa.mjs` 22 маршрутты (соның ішінде 11 дәстүр карточкасының маршруты) 11 өлшемде, барлығы 242 жұпта тексереді. [Өлшем деректері](audit.json); қосымша компьютер және көлденең бағыт кадрларының [өлшем деректері](audit-captures.json).

## Қаріптер

Noto Sans, Noto Serif және Noto Sans Mono Google Fonts жобасының [SIL OFL 1.1 лицензиясымен](../../../public/fonts/OFL.txt) WOFF2 түрінде жергілікті сақталды. Түпнұсқа [Noto Sans](https://github.com/google/fonts/tree/main/ofl/notosans), [Noto Serif](https://github.com/google/fonts/tree/main/ofl/notoserif) және [Noto Sans Mono](https://github.com/google/fonts/tree/main/ofl/notosansmono) репозиторийлерінен алынды. Сыртқы Google Fonts сілтемелері алынды.

`tools/verify-kazakh-fonts.py` жеткізілетін WOFF2 файлдарының `cmap` кестесін тікелей оқыды: Ә ә Ғ ғ Қ қ Ң ң Ө ө Ұ ұ Ү ү Һ һ І і әріптерінің ешқайсысы жетіспейді. Сұралған бес үлгі тіркестің таңбалары да түгел бар. Үшеуінің `wght` осі 100–900; браузерде 400, 500, 600, 700, 800 және 900 салмақтары жүктелді. UTF-8 тексеруі `src` пен `index.html` ішінде ауыстыру таңбасын немесе тексерілген бұзылған кодтау үлгілерін таппады. Тексеруді қайталау үшін Python `fonttools` және `brotli` пакеттері керек.

## Браузер нәтижелері

- [Маршрут және экран өлшемдері](audit.json): 242 жұпта беттің жалпы көлденең ығысуы тіркелмеді. 320 px AR режим түймелері мен дәстүр қойындылары өз қатарында көлденең сырғиды.
- [Әрекет нәтижелері](interaction-checks.json): 390 px көрінісінде мәзір мен Escape, тоғыз сахнаны ауыстырып жүктеу, бір саусақпен бұру, екі саусақпен жақындату, кезең және нысан таңдау, 844×390 бұрылу кезіндегі кенеп өлшемі, WebXR жоқ кездегі 3D балама, чат ұсынысы және көрме слайды өтті.
- [Сенсор нысан сынағы](touch-checks.json) және [pointer/click оқиғалары](tap-diagnostics.json): кенеп экранда тұрған кезде сүйреу нысанды кездейсоқ таңдамады, қысқа түрту көрінетін нысанның сипаттамасын ашты. Тексеру браузер эмуляциясында жасалды.
- [Сапа және қолжетімділік нәтижелері](quality-checks.json): мобильді 3× DPR 1.5-ке, компьютердегі 2× DPR 1.75-ке шектелді; қозғалысты азайту медиасұрауы тегіс жылжуды өшірді; қаріп салмақтары жүктелді; диалог ашылғанда фокус оған өтеді, Escape арқылы жабылып бастапқы түймеге қайтады.
- `npm run build` және `npm run models:validate` аяқталды. GLB тексергіші барлық тоғыз модельде қате мен ескерту таппады.
- AR беті бөлек жүктеледі: бастапқы JavaScript шамамен 939 KB (255 KB gzip), AR бөлігі 719 KB (184 KB gzip). Vite екі бөліктің де 500 KB шегінен асатынын ескертеді; баяу желідегі нақты жүктелу уақыты өлшенген жоқ.

## Тексерілмеген орта

Физикалық телефон не планшет, олардың экрандық пернетақтасы, камера рұқсаты, WebXR `immersive-ar` сессиясы, Safari және Firefox тексерілмеді. Chrome эмуляциясы нақты құрылғының сенсор дәлдігін, өнімділігін немесе камера AR жұмысын дәлелдемейді. Браузерде WebXR жоқ кездегі түсіндірме мен кәдімгі 3D-ға қайту тексерілді.
