# Zerde: аудит и техническая интеграция 3D

**Статус: техническая основа реализована; требование музейного качества не закрыто.** Добавлены три настоящих GLB, исходники сеток и интеграция в существующий сайт. Художественный финиш, браузерная проверка и испытания камеры на совместимом устройстве остаются невыполненными.

Репозиторий: https://github.com/Akhmad-Alisherovich/zerde.git . Исходная ревизия: `53eb5ae00ffd9c767ed3db6187d7c3e497bc597d`. До изменения файлов создана локальная ветка `feat/cultural-3d-scenes`. Push и публикация не выполнялись.

## Что выявил аудит

React 19, TypeScript strict, Vite 6, Tailwind, React Router. Трёхмерный стек — прямой Three.js 0.186 и OrbitControls, без React Three Fiber. Перевод проекта на другой рендерер не требовался. Все маршруты из `src/App.tsx` сохранены.

Существовали `CulturalSceneBuilder.ts`, `CharacterModelBuilder.ts` и `textureUtils.ts`. GLB, GLTF, Blender-файлов, загружаемых PBR-моделей и отдельного GLTFLoader не было. Люди были построены из простых геометрических деталей. Asar и Тұсаукесер переключали статичные состояния с пересозданием сеток. Автовращение имело устаревшее замыкание состояния, зум выполнялся относительно начала координат, удалённые материалы и текстуры не освобождались.

Предыдущий WebAR показывал модель поверх камеры и проверял яркость нескольких участков кадра. Он не распознавал Hiro и не вычислял 6DoF-положение маркера. Значения «tracking confidence» и «desk anchor» не доказывали пространственного отслеживания. Эта реализация заменена WebXR.

## Реализовано

| Файл | Размер | Уникальных сеток | Каналов анимации |
| --- | ---: | ---: | ---: |
| asar.glb | 8.57 МБ | 107 | 83 |
| nauryz.glb | 10.42 МБ | 51 | 0 |
| tusaukeser.glb | 5.79 МБ | 49 | 12 |

Число сеток и треугольников в `asset-stats.json` описывает уникальные экспортированные mesh-ресурсы, а не гарантированный бюджет GPU или измеренный FPS.

**Asar — первая созданная сцена.** Включает изогнутые деревянные сағанақтар, моделированные перевязи, сықырлауық, шаңырақ с радиальными отверстиями и күлдіреуішами, 64 изогнутых уық, ашалы бақан, отдельные панели туырлық и үзік, басқұр, түндік, запасные детали и трёх анатомических персонажей. GLB содержит 16-секундную временную шкалу: кереге 0–4 с; подъём шаңырақ 4–8 с; установка уық 8–12 с; киіз 12–16 с. В конце временный бақан скрывается. Раскрытие кереге и разворачивание ткани выполнены приближёнными трансформациями, а не физической симуляцией шарниров или ткани.

**Nauryz.** Открытая для изучения юрта, текемет, низкий дастарқан со льняным покрытием, астау, неровные сетки бауырсақ, тостағандар с көже, сосуд из кожи, самаурын и два анатомических взрослых персонажа. Передняя часть покрытия намеренно открыта. Расстановка — учебная композиция, а не реконструкция конкретного музейного объекта. Сцена статичная.

**Тұсаукесер.** Возрастной морф ребёнка, двое взрослых, ақ жол, двухпрядный бело-чёрный ала жіп и ножницы. 12-секундная шкала: подготовка, движение лезвий и смена замкнутой верёвки на две открытые половины с падением, затем перемещение ребёнка с движением костей ног. Контакт рук с ножницами и ног с дорожкой требует ручной анимационной доработки.

**Интерактивность.** GLTFLoader, AnimationMixer, 360° OrbitControls, исправленный зум вокруг цели камеры, выбор сеток по raycasting и унаследованным hotspot-метаданным, кнопки этапов, повтор этапа, воспроизведение всей шкалы, пауза и перемотка. Обрабатываются ошибки WebGL и загрузки GLB. Загрузка безопасна при размонтировании и React StrictMode; освобождаются геометрия, материалы, текстуры, скелеты, контроллеры и shadow map. Учитывается prefers-reduced-motion.

**WebAR.** В коде подключены immersive-ar, hit-test, viewer/local reference spaces, указатель поверхности, размещение по реальному hit-test pose, масштаб, поворот, повтор анимации, окончание сессии и возврат к 3D. Перед запуском проверяются HTTPS и isSessionSupported. Добавлена передача URL того же GLB в Android Scene Viewer. Старый Hiro SVG сохранён как архивный материал и явно обозначен как неиспользуемый текущим WebXR. iOS Quick Look/USDZ не добавлен. На браузерах без WebXR остаётся 3D-режим.

AI-чатбот, учебные карточки, исследовательские страницы, плакаты, режим выставки и роутер не менялись. Уточнён только технический текст AR-галереи и её тип отслеживания.

## Проверки и ограничения

- Исходная и итоговая сборки `npm run build` проходят: TypeScript + Vite. В сборке остаётся предупреждение о крупном JS chunk; оно существовало и до изменений.
- `npm run models:validate` проходит. Khronos glTF Validator: 0 ошибок и 0 предупреждений для каждой из трёх моделей. Полные результаты: `docs/validation/gltf-validation.json`.
- Настоящий Three.js GLTFLoader разбирает все три GLB. Проверены 53-костные скелеты, 7/11/3 hotspot-группы, реальные изменения translation/rotation/scale, концы этапов, разрезанные половины жіп, перемотка и освобождение геометрии. Результаты: `docs/validation/integration-tests.json`.
- Эти тесты выполняются без GPU. Bitmap-дескрипторы заглушены; они не проверяют отображение материалов, визуальную достоверность или фактическую производительность.
- Попытка открыть запущенное приложение в облачном браузере, включая одну повторную попытку по основному адресу, завершилась `net::ERR_BLOCKED_BY_CLIENT`. Поэтому реальных скриншотов работающего сайта нет. Рендеры и 2D-референсы не выдаются за скриншоты.
- Камера, WebXR-размещение, Android Scene Viewer, iOS и поведение на телефонах не проверены. Наличие реализации и успешная сборка не означают, что AR испытан на устройстве.
- Blender отсутствует; загрузка бинарного дистрибутива получила HTTP 403, пакет bpy не был доступен. Поэтому предоставлены редактируемые `.gltf` + `.bin`, исходный Python-генератор, OBJ, морфы и определения скелета, но не `.blend`.

**Что осталось до требуемого музейного результата.** Ручная посадка чапанов и женского костюма, головные уборы и волосы, реалистичные кожи/ткань, возрастные признаки старших персонажей, точный хват и совместная работа с деталями, посадка ног, проверка пересечений, качество освещения со всех углов, визуальная проверка нормалей и UV. Одежда сейчас представляет процедурную оболочку поверх детальной анатомии. Это не законченный музейный персонаж. Нужны этнографическая проверка форм и региональных деталей, реальная браузерная QA, скриншоты и испытание AR на совместимом Android-устройстве. Mobile FPS, память и LOD пока не измерены.

## Работа с результатом

Для запуска сайта модели уже готовы:

```bash
npm ci
npm run build
npm run dev
```

Открыть `/ar-gallery?scenario=ar-asar`, затем проверить все четыре этапа и полное воспроизведение. Далее — `/ar-gallery?scenario=ar-nauryz` и `/ar-gallery?scenario=ar-tusaukeser`. Остальные маршруты сохранены.

Для воспроизводимой правки моделей использовать Python 3 и Node.js 24 (проверенная версия; интеграционный тест использует встроенное чтение TypeScript):

```bash
python -m pip install -r tools/modeling/requirements.txt
npm run models:build
npm run models:validate
```

Для импорта в Blender использовать файлы из `tools/modeling/scenes/`, сохраняя соседние `.bin`. Оптимизированные GLB лежат в `public/models/`; PBR-карты — в `public/models/textures/`. Происхождение и лицензии описаны в `public/models/ASSET_PROVENANCE.md`.

Архив содержит существующий проект с локальными изменениями, исходники и отчёт. Он не содержит node_modules, временную сборку и Git-служебные данные. Изменения не отправлены в удалённый репозиторий.
